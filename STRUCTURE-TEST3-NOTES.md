# Structure Test 3 — targeted, conservative changes

- Removed WDA Coliseum from Ambient Odyssey's EXTRA mixed placement pool. Its native WDA major placement remains enabled, preserving rare natural appearances without artificially boosting frequency.
- Split WDA Small Blimp from the extra land/sky mixed pool into its own placement set (spacing 24, separation 12) to make it eligible for independent placement attempts. This is a candidate-frequency change, NOT a verified increase in visible sky structures; underlying biome tags and structure height rules still apply.
- Left Bathhouse enabled. Its native minor group is shared with other minor WDA structures; changing the group would also affect those, so individual frequency is not adjusted in this pass.
- No claims about avoiding cross-mod structure collisions: placement exclusion compatibility still needs runtime evidence.
- No broad worldgen/biome or client mod changes. Test on a NEW world, ideally matching seed/settings, and record exact coordinates and biome IDs for blimps, Coliseums, Bathhouses, and overlaps.
- The previous locate survey had 164 completed results rather than the planned 180, and is not a density measurement. Avoid using it as the sole acceptance test.
