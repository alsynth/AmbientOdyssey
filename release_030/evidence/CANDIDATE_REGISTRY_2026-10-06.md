# Ambient Odyssey — Candidate Registry (2026-10-06)

This is the counted research backlog, not an install list. Mutually exclusive alternatives are intentionally counted separately because the purpose is to preserve every candidate worth auditing.

Status legend: **HIGH** = actively promising; **MED** = good but conditional/overlap audit; **LOW** = only if its niche survives later design; **WATCH** = promising concept but too new/risky; **REPLACE** = evaluate as an alternative, not stacked; **LATE** = deliberately postpone to balance/polish.

## Count

**166 individually named candidates are currently worth preserving for an audit.** This does **not** mean 166 should be installed: the count deliberately includes datapacks/integration utilities and diagnostics as well as competing biome stacks, competing skill trees, alternative End-city mods, competing multiplayer boss-scaling approaches, Connector experiments, and late polish/performance tools. Spark, AppleSkin, Mouse Tweaks and Reliquified Artifacts were explicitly *not* re-added to this future count after reconciliation because they are already active in v0.2.9.

The design goal is to add the winners rather than blindly maximize this number, **but Ambient Odyssey is intentionally aiming for eventual Ascendra-class breadth**. The current stabilization pause is temporary; once the foundation is healthy, resume controlled waves toward a genuinely huge long-form pack.
