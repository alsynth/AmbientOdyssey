## Dependency
Every AO addition uses the loot modifier type `irons_spellbooks:append_loot`. If Iron's Spellbooks renames or removes it,
the modifiers fail to load (one log error each) and **the additions silently stop**; chests then roll only their native pools.

## Fallback if Paxi loses priority
Copy this folder into `<world>/datapacks/`, then run `/datapack enable "file/ao_ancient_city_t5"` and `/reload`
(or create the world with it). Templates only apply to chunks generated afterwards.
