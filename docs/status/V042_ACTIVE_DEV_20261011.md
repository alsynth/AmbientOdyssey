## Important divergent balancing branch recovered from older GitHub history

The separate `experimental/v041-balance-lab-dungeon-difficulty-20261011` branch is **ahead by 10 and behind by 15 commits** relative to the former v0.4.1 worldgen-safety source. It is *not integrated* into the current 329-project Quest/TREK build. Its native pilot `experiments/ao-balance-lab/config/dungeon_difficulty_v2.json` covers only six named structures with modest vanilla-hostile health/damage/armor changes. It intentionally disables loot scaling, per-player scaling and spawner-count scaling; it is not the full nine-tier dungeon/boss rebalance.

**Packaging drift:** `tools/package_ao_balance_lab.py` on that divergent branch hard-codes a two-addon baseline including `ao-questlog-betterinventory-0.1.1.jar`, whereas the latest candidate has three AO addons, Questlog bridge 0.1.2 and the separate proposed Hominid worldgen-safety 0.1.1. Never apply that old packager directly to the current combined ZIP. It needs a source-preserving port and strict three-addon, 329→330 reference checks.

Two other user-originated balance requests remain researched only:
- [Goblin-Tuned trade economy](../../docs/balance/V041_GOBLIN_TUNED_TRADE_ECONOMY.md) on the divergent lab branch: user wanted the original armor benefit retained but high-value chainmail trade costs raised; original chains are very cheap, while Netherite is expensive. **No price override is implemented in current pack.** Trade JSON (including native component-bearing outputs) must be patched by native file key, not through spawn-rate config.
- [Random cosmetic trims on Apotheosis affix drops](../../docs/balance/V041_APOTHEOSIS_RANDOM_AFFIX_TRIMS_DESIGN.md): source research establishes that the 1.21 Apotheosis `apotheosis:rarity`/affixes components can be distinguished from vanilla rarity and that a GLM after affix roll could decorate armor without changing stats. **No working custom GLM/addon has been compiled or tested yet**; player-requested 100% trims is design-only.

These are significant pending milestones, **not forgotten omissions to silently install or auto-balance**. Keep them isolated until technical stability and a loot economy sample are available.
