## Universal candidate intake gate — apply to *every* row of the nine-themed audit once it arrives

1. **Identity/ownership:** exact CurseForge/Modrinth project ID, NeoForge **1.21.1** jar ID and required deps, side/server requirements, license/modpack redistribution; no Fabric connector unless explicitly tested.
2. **Overlap map:** name its installed owner(s) above, distinguish **actual registry ID conflict / documented dependency** from **duplicate gameplay purpose**; consider configs or data tags instead of adding another mod.
3. **Technical integration:** entry points (mixin rendering, NeoForge capability/Curios/Accessories, FTB quests, loot tables, biome modifiers, spawn placements, structure sets, recipes).
4. **Baseline-and-delta:** compare fresh world and server Spark metrics to Test8.10 (chunk-gen ~6.76/s under a high-load singleplayer route; **not a deterministic benchmark**). Record spawns, FPS/frametimes, TPS and RAM on a controlled route.
5. **Batching:** keep **wildlife**, **combat/gear**, **farming/food**, **engineering**, **render/QoL**, and **worldgen/dimension** additions separately testable; avoid batching two mods that override the same registry or GUI.
6. **Selection:** record **KEEP / CONDITIONAL / REJECT / DEFER**, objective gain, exact conflicts, existing alternative, mitigation, test command/check, source link and whether the user approved the mod.
7. **Rollbacks:** preserve Test8.10 known-running baseline and current immutable release lock. **No new release ZIP** until themed shortlist is present and user-approved.
