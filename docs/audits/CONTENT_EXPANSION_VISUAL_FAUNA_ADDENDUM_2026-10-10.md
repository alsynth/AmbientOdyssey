| System | Effect | Integration/selection |
|---|---|---|
| **Euphoria Patches + current Complementary shader r5.9.3** | **Shader/client seasons** recolor foliage, provide rendered snow/winter/autumn look based on shader/world time; no real server crop-growth/weather/cold changes. ## Resource pack conflict groups and test order
- **A: Foliage:** Polytone + rainbow's foliage; test shader shadows High, 1.21.1 assets, BWG/BOP/RU leaves, tree/shader FPS. Then Os' Colorful Grasses Mix and Bushy Petals, then Foxified Dense Flowers **one at a time**, and compare enabled/disabled. Do not require all players to use High shader shadows.
- **B: Connected surfaces:** Bricks/Paths/Rocks share a **Continuity or OptiFine dependency**. This is a **later separate renderer research**; do not add packs and call them working if no renderer is loaded. Prioritize a native NeoForge compatible CTM solution with Embeddium.
- **C: Warm lights:** Torches Reimagined first, then Extended Illumina stack order, Swinging Lanterns client mod independently; Polytone only for optional sounds, verify existing Amendments.
- **D: Living ambience:** user-priority **Cosy Critters** upstream native client mod, A/B audio (Atmosfera Neo **versus** AmbientSounds 6), very cautious additional particles.
- **E: Seasons:** Euphoria visual shader seasons FIRST, server Serene Seasons in isolated separate trial ONLY if players want real winter/crop mechanics.
