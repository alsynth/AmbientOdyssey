### Evidence and dependency closure
- **Dimensional Dungeons** author supports NeoForge 1.21.1 v210 (Sep 7), claims compatibility with Artifacts mimics, End Remastered keys, Lootr chests and JEI. Dungeons use their own dimension, generated only on key activation, avoiding more Overworld structure spam. Source: https://www.curseforge.com/minecraft/mc-mods/dimensional-dungeons
- **Ancient Remnants** 1.5.2 (Oct 6), requires NeoForge Fragmentum; currently inherited from Aquamirae. Supports rare monuments, player research/codex and blessings. Upstream common config defaults placement spacing 100/separation 20 for six structures; three default to specific vanilla biomes and two forest/taiga tags. In FTF, inspect real terrain and modded biome eligibility before making them more common. Sources: https://www.curseforge.com/minecraft/mc-mods/ancient-remnants and https://github.com/ObscuriaLithium/ancient-remnants/blob/main/common/src/main/java/dev/obscuria/remnants/config/CommonConfig.java
- **TarotCards Remastered** 2.3.5 uses Fzzy Config (already in AO), and supports Curios + FTB Teams. These are rare collectible loot bonuses in existing structures. Upstream default deck of 22 and potent passive cards should be restricted later using source-confirmed `tarot_deck_size`, `require_card_in_curio`, `loot.default_loot_chance`, with actual config format verified before overriding. Sources: https://www.curseforge.com/minecraft/mc-mods/tarotcards-remastered and https://github.com/Suel-ki/TarotCards-Remastered/blob/main/common/src/main/java/io/github/suel_ki/tarotcards/core/config/TarotConfig.java
- **Aquaculture Delight** is a deliberate bridge between existing Aquaculture 2 and Farmer's Delight. No second fishing framework, additional dependencies or added biome generator. Source https://www.curseforge.com/minecraft/mc-mods/aquaculture-delight/files/6179576
- **End Remastered Additions** adds optional routes tied to fishing, trial chambers, Ancient Cities, Aether and BOMD; new eyes are not intended as a new required all-eyes grind. Source https://www.curseforge.com/minecraft/mc-mods/end-remastered-additions/files/9111385
